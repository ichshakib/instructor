# OnlineLMS Image Assets Guide

Place your custom image assets in this directory (`apps/web/public/images/`):

### 1. Main Hero Student Image
- **File Name:** `hero-student.png`
- **Recommended Size:** `800px × 950px` (or higher resolution @2x)
- **Format:** Transparent PNG or WebP
- **Description:** Photo of a student / graduate celebrating or jumping in graduation cap and gown with a diploma and smile, with the background removed (transparent cutout).

### 2. Learner Avatars (for Social Proof "29.5k+")
- **File Names:**
  - `avatar-1.jpg` (or `.png`)
  - `avatar-2.jpg` (or `.png`)
  - `avatar-3.jpg` (or `.png`)
  - `avatar-4.jpg` (or `.png`)
- **Recommended Size:** `160px × 160px` (1:1 square/circle)
- **Format:** JPG, WebP, or PNG
- **Description:** Headshot photos of diverse students/learners.

*Note: The landing page includes graceful, beautifully styled interactive placeholders and fallback states so the design looks complete and polished even before these files are added.*
